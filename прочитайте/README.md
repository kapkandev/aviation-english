## Запуск

1. Скачайте или распакуйте папку проекта целиком.
2. Не перемещайте и не переименовывайте файлы внутри `photo/` и `video/`: они используются страницей.
3. Откройте файл `index.html` двойным щелчком.

Для работы локальных видео оставьте ролики в папке `video/`:

- `video/aviation1.mp4`
- `video/aviation2.mp4`

Заставка использует изображение `photo/tatkga.png`.

## Тест

Перед началом укажите имя, фамилию и группу. В каждой попытке из банка 30 вопросов случайно выбираются 10, без повторов внутри одной попытки. После выбора ответ блокируется: правильный вариант подсвечивается зеленым, ошибочный — красным. Вернуться и поменять ответ нельзя. В конце показываются число правильных ответов и ошибок.

Для новой попытки нажамите **Take the test again**.
